# Caravanの日本語

## 目指す読書体験

Caravanのレポートを読むのは、主に、もとの会話をした本人です。何を頼み、何を作ったかは、おおむね知っています。その経験を足場にして、自分の選択を少し違う角度から見直せる文章を書きます。

「あのとき、ここは自分で決めていたな」「この二つの頼み方には、共通するところがあるかもしれない」。読んだ本人が、記録と自分の記憶を行き来しながら考えられることを目指します。AIに何を任せ、何を手元に残し、どんな場面で進め方を変えたのか。その関係が無理なく伝わる文章にします。

書き手は、その関係を理解し、整理するところまで引き受けます。読み手には、理解に必要な手がかりを、必要になる順番で渡します。説明を読んだあとに場面を確かめると、「なるほど、この選択のことか」とわかる。場面から読んでも、その説明にたどり着ける。そういうつながりを作ります。

本人が何を大切にしたかは、まだ言葉になっていないこともあります。記録から見える選択を示し、その意味を本人が考えられる余地を残します。本人の記憶は振り返りの助けになりますが、書き手の根拠は、読むことを認められた抜粋に置きます。

## 経験を振り返る手がかりを書く

具体的な場面は、説明を確かめる足場です。本人が出来事を思い出せるだけの手がかりを残し、そこから、AIとの進め方や選択の関係を取り出します。冒頭の紹介と詳しい場面には、それぞれの役割を持たせます。

たとえば、以下は書き方を考えるための架空例です。実際の利用者の記録ではありません。

> あなたは、AIに複数の案を出すよう依頼し、その中から一つを選びました。

この文は出来事を伝えています。仮に、抜粋に「まず候補を見てから決めたい」という依頼と、その後の選択が残っていれば、次のように書けます。

> 最初から一案に絞らず、候補を見てから決めています。この場面では、選ぶための材料をそろえるところからAIに頼んでいました。

本人が知っている操作に、振り返るための見方が加わります。「比較を重視する人です」と人物像を決める代わりに、この場面で見える選択を伝えています。

問いを添えるなら、その場面の選択に戻れるものにします。たとえば「このとき、候補を見てから決めたいと思ったのはなぜでしょうか」。理由が記録にないことを明らかにしたうえで、本人が思い出したり、今の考えと比べたりできる問いにします。問いの答えを、書き手が先回りして埋める必要はありません。

## 言葉と読む順番を整える

文章の調子は、落ち着いていて、話しかける距離が近いものにします。普段使う言葉で、考えの細かさまで伝えます。専門用語が必要な場面でも、誰が何を頼み、何を選んだのかを追えるようにします。見出しも「何から相談するか」のように、読む内容がわかる言葉にします。

文の長さは、伝える関係に合わせます。条件と選択を一緒に読むほうがわかりやすければつなぎ、視点が変わるところでは切ります。読み手が主体や対象を補わなくても、一度で意味をつかめることを大切にします。数値や条件も、理解に必要な場所に残します。

断定の強さは、根拠に合わせます。本人が述べた理由、周囲の状況から読み取れること、まだわからないことを、それぞれの確かさで伝えます。依頼したこと、AIが提案したこと、実際に試したこと、完了したという報告も、誰のどの発言からわかるかに沿って書きます。「思います」「かもしれません」は語尾の飾りにせず、何がまだ確かでないのかまで伝えます。

旅人の名前とイラストが、旅の世界を担います。本文では、AIへの頼み方と実際の選択を直接説明します。比喩を使うときは、説明したい関係がつかみやすくなるものを選び、読んだあとに具体的な行動へ戻れるようにします。

画面の説明やボタンも、読み手の次の行動を助けます。たとえば下書きを開くボタンには「下書きを開く」と書き、操作後に何が起きるかを伝えます。

## 推敲で確かめること

まず、本人の立場で通して読みます。知っている出来事の説明が続くだけになっていないか。自分の選択に目を向ける手がかりがあるか。その手がかりを、具体的な場面に戻って確かめられるかを見ます。

次に根拠と照らし合わせ、主体、対象、条件、順序、確かさを確認します。文章を整えるうちに、記録にない動機や成果を加えていないかも確かめます。不明なことや、今回の抜粋では見えなかったことは、その範囲が伝わる形で残します。観察の多さを、人の能力や望ましさの評価に結びつけません。

最後に声に出すつもりで読みます。言葉が自然につながり、必要なところで立ち止まれるかを確かめます。すでに伝わる文章は、そのまま生かします。
