# 0035: 中間・併用を保ち、紹介する旅人を別途選ぶ

- 状態: Accepted
- 記録日・決定日: 2026-11-04
- 記録種別: 新規決定
- 実装状況: 実装済み
- 関連ADR: [0002](0002-observations-and-type-summary.md)、[0007](0007-stable-standalone-reports.md)、[0033](0033-separate-collaboration-from-scene.md)

## 背景

中間・併用で候補が複数になると、タイプの画像がなくなる。複数の使い方がある観察を残しながら、結果を旅人の姿で受け取れるようにする。

## 決定と理由

4軸の観察と分類を変えず、同じ上限付き抜粋から、今回の会話を紹介する代表の旅人を候補内で別途検討する。割合の僅差ではなく、選択のつながりや任せ方を根拠にする。判断を独立したrepresentative-v1として理由・本人の発言参照・更新日時とともに保存する。一人に絞れなければnullを認め、候補の旅人を並べる。未レビューでも既存候補は表示できるが、代表を選んだとは表示しない。

新しい準備・確定コマンドを設け、同じ範囲への承諾と元サンプルの照合を行う。判断のキーはサンプル、保存済みportrait、候補の説明を含む。新しいportrait確定では代表の判断を除去する。分類・元の分析日時・共有JSONは変更しない。本人用バックアップには判断を含める。旧結果のrenderでは判断や根拠を追加しない。固定2ページと単独HTMLの出力を維持する。

## 比較対象

- 閾値を下げて必ず一タイプにする：中間・併用の観察を失う。
- 候補の先頭や割合の僅差で画像を選ぶ：意味を検討した判断と誤解させる。
- 代表を毎回必須にする：根拠のない選択が生じる。

比較は設計上の検討であり、精度の比較実験ではない。

## 影響・トレードオフ

中間でも画像を表示できる。追加レビューにはトークンと確認作業が必要。代表は編集上の判断であり、分類の確定や人物の本質を示さない。材料不足には代表を付けない。自由記述は集計共有JSONに含めない。

## 再検討する条件

代表と4軸が矛盾して見える、判断が候補の印象だけに依存する、候補が多いと画像を読めない場合。
